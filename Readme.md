# Tanglewire — Feedback & Support

> Found something strange?

This repository is the public feedback hub for **Tanglewire**.

Use it to report bugs, share feedback, suggest an idea, or tell us about
something unsettling you encountered in one of our games.

## Before opening an issue

- Search existing issues first. Your report may already exist.
- Use the matching form so we receive useful details.
- Be respectful. Horror is welcome; harassment is not.
- Do not share passwords, API keys, personal addresses, payment details,
  private logs, or other sensitive information.
- Do not post spoilers in an issue title. Use the issue body and clearly mark
  spoilers instead.

## What can I report?

| Type | Use it for |
| --- | --- |
| [Bug report](../../issues/new/choose) | Crashes, broken mechanics, visual problems, missing audio, performance issues, or anything behaving incorrectly |
| [Feedback](../../issues/new/choose) | Tell us what worked, what felt unsettling, what did not, or what you would like to see more of |
| [Suggestion](../../issues/new/choose) | Ideas for improvements, accessibility options, quality-of-life changes, or future experiments |

> [!WARNING]
> GitHub Issues are public.
>
